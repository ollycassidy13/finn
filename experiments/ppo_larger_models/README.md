# TinyDeiT PPO Folding Experiment

This experiment runs resource-aware PPO folding on a prepared TinyDeiT FINN/MLO
model. It reproduces the VCK190 search configuration used for the 200 FPS
experiment and also accepts newly prepared TinyDeiT ONNX models.

## Input model

The runner expects a specialized FINN hardware model containing one `FINNLoop`
and folding attributes such as `PE` and `SIMD`. A raw QONNX export cannot be
passed directly to the optimizer. Before starting PPO, the runner applies the
same shuffle decomposition, layer specialization, shape inference, and datatype
inference used by the original experiment. This exposes the complete folding
space in a newly prepared model.

The TinyDeiT preparation flow and model-specific operators are available on the
`feature/TinyDeiT-Tiled-VCK190` branch. Use a second worktree for that branch:

```bash
git fetch origin feature/TinyDeiT-Tiled-VCK190
git worktree add ../finn-tinydeit origin/feature/TinyDeiT-Tiled-VCK190
```

Starting from the W4A4 checkpoint, run this in the TinyDeiT worktree to produce
the required model as `tinydeit_mlo.onnx`:

```bash
python -m transformer_examples.tinydeit.prepare_model \
  --input onnx-checkpoints/deit_tiny_w4a4_quant.onnx \
  --output-dir transformer_examples/tinydeit/build/w4a4_prepare \
  --clock-ns 5.0 \
  --target-fps 200 \
  --save-intermediate
```

The quantized QONNX checkpoint is generated by the
[Quantization-Variation](https://github.com/HuangOwen/Quantization-Variation)
TinyDeiT flow and is not stored in this repository.

## Reproduce the PPO search

Run with the TinyDeiT worktree's FINN Docker environment so its custom operators
are registered. Mount this PPO worktree into that container; the runner then
loads the PPO implementation from `--ppo-root`. Vivado 2024.2 must be configured
so version-dependent cycle estimates are available.

```bash
export PPO_ROOT=/path/to/finn-ppo
export TINYDEIT_ROOT=/path/to/finn-tinydeit
cd "$TINYDEIT_ROOT"
FINN_DOCKER_EXTRA="-v $PPO_ROOT:$PPO_ROOT" ./run-docker.sh python \
  "$PPO_ROOT/experiments/ppo_larger_models/run_tinydeit_ppo.py" \
  --ppo-root "$PPO_ROOT" \
  --model "$TINYDEIT_ROOT/transformer_examples/tinydeit/build/w4a4_prepare/tinydeit_mlo.onnx" \
  --output-dir "$TINYDEIT_ROOT/build/tinydeit-ppo-200fps" \
  --board VCK190 \
  --fpga-part xcvc1902-vsva2197-2MP-e-S \
  --clock-ns 5.0 \
  --target-fps 200 \
  --episodes 2 \
  --rollout-steps 32 \
  --update-epochs 4 \
  --seed 0
```

The runner writes:

- `folded.onnx`: the optimized FINN model;
- `result.json`: target and estimated performance, resource estimates, device
  capacity, search settings, and runtime.

At 200 MHz and 200 FPS, the optimizer targets 1,000,000 cycles per external
frame. The search evaluates the full TinyDeiT `FINNLoop` hierarchy against one
VCK190 resource budget.

Generated models and result directories should be written outside the source
tree and are not committed to this branch.
